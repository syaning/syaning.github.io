**Approach:** Recursive fast exponentiation; negative n becomes reciprocal; square the half-power and multiply an extra x when n is odd.

**Complexity:** O(log|n|) time, O(log|n|) space

::: code-group

```js
/**
 * @param {number} x
 * @param {number} n
 * @return {number}
 */
var myPow = function(x, n) {
  if (n < 0) {
    return 1 / myPow(x, -n)
  }
  if (n === 0) {
    return 1
  }
  var half = myPow(x, n / 2 >> 0)
  return n % 2 === 0 ? half * half : half * half * x
}
```

```py
class Solution(object):

    def myPow(self, x, n):
        """
        :type x: float
        :type n: int
        :rtype: float
        """
        if n < 0:
            return 1 / self.myPow(x, -n)
        if n == 0:
            return 1
        half = self.myPow(x, n // 2)
        return half * half if n % 2 == 0 else half * half * x
```
