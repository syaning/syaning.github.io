**Approach:** Stack of [value, runningMin] pairs so getMin is O(1).

**Complexity:** O(1) per op, O(n) space

::: code-group

```py
class MinStack(object):

    def __init__(self):
        """
        initialize your data structure here.
        """
        self.data = []

    def push(self, x):
        """
        :type x: int
        :rtype: void
        """
        if len(self.data) == 0:
            self.data.append([x, x])
        else:
            self.data.append([x, min(self.data[-1][1], x)])

    def pop(self):
        """
        :rtype: void
        """
        a = self.data.pop()
        return a[0]

    def top(self):
        """
        :rtype: int
        """
        return self.data[-1][0]

    def getMin(self):
        """
        :rtype: int
        """
        return self.data[-1][1]
```
